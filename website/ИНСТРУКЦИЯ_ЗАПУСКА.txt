🚀 ИНСТРУКЦИЯ ПО ЗАПУСКУ САЙТА
=====================================

СПОСОБ 1 (САМЫЙ ПРОСТОЙ):
=========================
1. Дважды кликните на файл "start_site.bat"
2. Дождитесь запуска сервера
3. Откройте браузер и перейдите по адресу: http://localhost:8000

СПОСОБ 2 (ЧЕРЕЗ КОМАНДНУЮ СТРОКУ):
==================================
1. Откройте командную строку в папке с сайтом
2. Выполните команду: python webserver.py
3. Откройте браузер и перейдите по адресу: http://localhost:8000

СПОСОБ 3 (ПРЯМОЙ ЗАПУСК):
=========================
1. Дважды кликните на файл "index.html"
2. Сайт откроется напрямую в браузере

СПОСОБ 4 (ЧЕРЕЗ ИНСТРУКЦИИ):
============================
1. Дважды кликните на файл "ЗАПУСК_ПРОСТОЙ.html"
2. Следуйте инструкциям на странице

ЕСЛИ PYTHON НЕ НАЙДЕН:
======================
1. Скачайте Python с https://python.org
2. При установке ОБЯЗАТЕЛЬНО отметьте "Add Python to PATH"
3. Перезапустите командную строку
4. Попробуйте снова

НАСТРОЙКА TELEGRAM БОТА:
========================
1. Откройте файл "config/bot-config.js"
2. Замените "YOUR_BOT_TOKEN_HERE" на токен вашего бота
3. Замените "YOUR_CHAT_ID_HERE" на ваш Chat ID
4. Подробная инструкция в файле "TELEGRAM_SETUP.md"

🚀 Запуск сайта

Выберите способ запуска:

🌐 Открыть сайт напрямую

📋 Инструкции по запуску:

Способ 1 (Самый простой):
Дважды кликните на файл start_site.bat
Способ 2 (Через командную строку):
Откройте командную строку в этой папке и выполните:
python webserver.py
Способ 3 (Прямой запуск):
Просто откройте файл index.html в браузере
⚠️ Важно:
Если Python не найден, скачайте его с python.org
При установке обязательно отметьте "Add Python to PATH"
После запуска сервера:
Откройте браузер и перейдите по адресу:
http://localhost:8000

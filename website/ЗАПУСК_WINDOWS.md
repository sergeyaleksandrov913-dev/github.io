# 🚀 Запуск сайта на Windows

## 🎯 Быстрый запуск (Рекомендуется)

### Способ 1: Через batch файл
1. Дважды кликните на файл **`start.bat`**
2. Дождитесь запуска сервера
3. Откройте браузер и перейдите по адресу: **http://localhost:8000**

### Способ 2: Через PowerShell
1. Откройте PowerShell в папке с сайтом
2. Выполните команду: `python server.py`
3. Откройте браузер и перейдите по адресу: **http://localhost:8000**

### Способ 3: Прямой запуск
1. Дважды кликните на файл **`start.html`**
2. Следуйте инструкциям на странице

## ⚙️ Настройка Telegram бота

1. Откройте файл `config/bot-config.js`
2. Замените `YOUR_BOT_TOKEN_HERE` на токен вашего бота
3. Замените `YOUR_CHAT_ID_HERE` на ваш Chat ID
4. Подробная инструкция в файле `TELEGRAM_SETUP.md`

## 🔧 Решение проблем

### Python не найден
- Скачайте Python с https://python.org
- При установке отметьте "Add Python to PATH"
- Перезапустите командную строку

### Порт занят
- Закройте другие программы, использующие порт 8000
- Или измените порт в файле `server.py`

### Ошибки в PowerShell
- Запустите PowerShell от имени администратора
- Или используйте `start.bat` вместо PowerShell

## 📱 Тестирование

1. Откройте сайт в браузере
2. Проверьте все разделы меню
3. Протестируйте форму обратной связи
4. Проверьте адаптивность (измените размер окна)

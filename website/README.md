# Сайт для создания сайтов на заказ

Современный рекламный сайт с дизайном в стиле iPhone, выполненный в оранжевых тонах с эффектом стекла.

## 🚀 Особенности

- **Современный дизайн** в стиле iPhone с оранжевой цветовой схемой
- **Эффект стекла** (glassmorphism) для всех элементов
- **Адаптивная верстка** для всех устройств
- **Прозрачное меню** с эффектами при наведении
- **Переключатели в стиле iPhone** вместо обычных чекбоксов
- **Интеграция с Telegram ботом** для обработки форм
- **Анимации и плавные переходы**
- **SEO-оптимизация**

## ⚙️ Настройка

### 1. Настройка Telegram бота

1. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram
2. Получите токен бота
3. Узнайте свой Chat ID (можно через [@userinfobot](https://t.me/userinfobot))
4. Откройте файл `config/bot-config.js`
5. Замените `YOUR_BOT_TOKEN_HERE` на токен вашего бота
6. Замените `YOUR_CHAT_ID_HERE` на ваш Chat ID

```javascript
const BOT_CONFIG = {
    BOT_TOKEN: '1234567890:ABCdefGHIjklMNOpqrsTUVwxyz',
    CHAT_ID: '123456789',
    // ... остальные настройки
};
```

### 2. Добавление фонового изображения

1. Поместите ваше изображение в папку `images/`
2. Откройте файл `css/style.css`
3. Найдите секцию `.hero` и добавьте:

```css
.hero {
    background-image: url('../images/your-background.jpg');
    /* остальные стили */
}
```

## 🚀 Запуск

1. Откройте файл `index.html` в браузере
2. Или запустите локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен)
npx serve .

# PHP
php -S localhost:8000
```

Затем откройте `http://localhost:8000` в браузере.

# 🚀 Инструкция по запуску сайта

## Быстрый старт

### Вариант 1: Простой запуск
```bash
cd website
python3 start.py
```

### Вариант 2: Ручной запуск
```bash
cd website
python3 server.py
```

### Вариант 3: Без Python
Просто откройте файл `index.html` в браузере

## 🌐 Доступ к сайту

После запуска сервера откройте в браузере:
- **http://localhost:8000** - основной сайт
- **http://localhost:8000/index.html** - альтернативный адрес

## ⚙️ Настройка Telegram бота

1. Откройте файл `config/bot-config.js`
2. Замените `YOUR_BOT_TOKEN_HERE` на токен вашего бота
3. Замените `YOUR_CHAT_ID_HERE` на ваш Chat ID
4. Подробная инструкция в файле `TELEGRAM_SETUP.md`

## 📱 Тестирование

1. Откройте сайт в браузере
2. Проверьте все разделы меню
3. Протестируйте форму обратной связи
4. Проверьте адаптивность (измените размер окна)

## 🛠 Остановка сервера

Нажмите `Ctrl+C` в терминале

# Настройка Telegram бота для сайта

## 📋 Пошаговая инструкция

### Шаг 1: Создание бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Введите имя для вашего бота (например: "WebStudio Contact Bot")
4. Введите username для бота (например: "webstudio_contact_bot")
5. Скопируйте полученный токен (выглядит как: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 2: Получение Chat ID

1. Найдите [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте любое сообщение боту
3. Скопируйте ваш Chat ID (число, например: `123456789`)

### Шаг 3: Настройка конфигурации

1. Откройте файл `config/bot-config.js`
2. Замените `YOUR_BOT_TOKEN_HERE` на токен из шага 1
3. Замените `YOUR_CHAT_ID_HERE` на Chat ID из шага 2

```javascript
const BOT_CONFIG = {
    BOT_TOKEN: '1234567890:ABCdefGHIjklMNOpqrsTUVwxyz', // Ваш токен
    CHAT_ID: '123456789', // Ваш Chat ID
    // ... остальные настройки
};
```

### Шаг 4: Тестирование

1. Откройте сайт в браузере
2. Нажмите кнопку "Связаться с нами"
3. Заполните форму и отправьте
4. Проверьте, что сообщение пришло в ваш Telegram

## 🔧 Дополнительные настройки

### Настройка уведомлений об ошибках

Бот автоматически отправляет уведомления об ошибках JavaScript на сайте. Это поможет отслеживать проблемы.

### Настройка сообщений

Вы можете изменить формат сообщений в файле `js/telegram-bot.js`, функция `formatMessage()`.

### Безопасность

⚠️ **Важно**: Никогда не публикуйте токен бота в открытом доступе! Используйте переменные окружения или серверную часть для продакшена.

## 🐛 Решение проблем

### Бот не отвечает
- Проверьте правильность токена
- Убедитесь, что бот запущен (отправьте `/start` боту)
- Проверьте Chat ID

### Ошибка CORS
- Telegram Bot API не поддерживает CORS из браузера
- Для продакшена используйте прокси-сервер или серверную часть

### Сообщения не приходят
- Проверьте, что бот добавлен в контакты
- Убедитесь в правильности Chat ID
- Проверьте консоль браузера на ошибки
